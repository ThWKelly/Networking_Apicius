Repository of datasets and images categorising and organising the recipies and ingredients found in Apicius 'de re coquinaria' This repository accompanies the paper: 'Mapping Elite Roman Culinary Identities: A Network Analysis of Apicius’ De Re Coquinaria.'

Structure:
-Large Scale Master Dataset containing fully transcribed and lemmatized CSV file containing all of the ingredients and recipies attributed to the corpus
-Images Created For Use In Essay
-Ingredient-Type annotation tables with comments outlining decisions made in the master dataset and
-Smaller Compliation CSV files specialised for data analysis
